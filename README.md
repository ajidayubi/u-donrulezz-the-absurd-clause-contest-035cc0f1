A program that writes one absurd clause buried deep inside a terms-of-service agreement: deadpan legal boilerplate that quietly turns absurd. On termination, the user's consciousness must be returned the way a defective toaster would be — in its original packaging, postage at the user's own expense, within thirty (30) days. It reads like real boilerplate until the word "consciousness" lands, and the joke is over in one clean sentence.

The clause: "The User agrees that, upon termination, their consciousness shall be returned in its original packaging, postage to be borne by the User, within thirty (30) days." Running the program writes exactly that line (162 characters) to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
